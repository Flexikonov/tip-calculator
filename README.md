# Tip Calculator - калькулятор чаевых

Простой инструмент на Python для быстрого расчёта суммы счёта в ресторане с чаевыми (15-20%)

## Описание проекта

Программа запрашивает у пользователя сумму счёта и мгновенно вычисляет:
*   Размер чаевых в 15-20%;
*   Итоговую сумму к оплате для каждого варианта

Полезен, когда нужно быстро прикинуть бюджет или разделить счёт между друзьями.

## Технологии

*   **Язык:** Python 3.x
*   **Библиотеки:** только стандартные (встроенные функции `input()`, `print()`, `float()` и арифметические операции)
*   **Контроль версий:** Git / GitHub

## Установка

Проект не требует установки дополнительных зависимостей. Достаточно иметь установленный Python 3 (версии 3.6 или выше).
